# MVVM Flutter Boilerplate (Material 3 modern login)

Ready-to-run Flutter project with:
- MVVM architecture
- Provider for state management
- GetIt for dependency injection
- Dio for networking
- Login screen (ReqRes API) with modern Material 3 design
- User list after login

To run:
1. Unzip and open in VSCode or Android Studio
2. Run `flutter pub get`
3. Run `flutter run`
